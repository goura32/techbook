# Target Reader

## 想定読者

- Git は使っているが、履歴やレビューの設計に自信がない人
- 個人開発からチーム開発へ進みたい人
- GitHub を単なるホスティング以上に活用したい人
- すでにチーム開発をしているが、運用が場当たり的で苦しさを感じている人

## 前提知識

- `clone` `commit` `push` `pull` 程度の基本操作
- 開発プロジェクトに参加した経験
- Pull Request を 1 度は作成した経験があると読みやすい

## 読了後の到達目標

- 読みやすい履歴とレビューしやすい変更単位を作れる
- ブランチ戦略とリリース運用をチーム事情に合わせて選べる
- トラブル時に慌てず復旧方針を立てられる
- GitHub の保護設定、rulesets、merge queue を運用の文脈で理解できる

## 読み進め方の目安

- Git 操作に不安がある読者は 1章から5章を先に読むと土台が固まりやすい
- GitHub の設定や CI との接続が気になる読者は 1章、4章、6章、7章を主軸にするとつながりやすい
- チームの運用改善が目的なら 1章から4章、8章から11章を先に押さえると効果が高い

## 対象外

- GitHub Actions だけに特化した詳細解説
- Git の内部実装だけを深掘りする低レイヤ本
- 完全初心者向けの最初の 1 冊
- 自己ホスト Git サーバーや GitHub Enterprise Server 固有の管理運用
