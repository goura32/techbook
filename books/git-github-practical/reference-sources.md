# Reference Sources

## 目的

- `参考情報` 欄へ最終転記する候補を、本書で使った主張と対応づけて管理する
- KDP 用の後付へ転記するときに、リンク集ではなく本文に効いている情報だけを残す

## 優先候補

### Git

1. Git Documentation  
   種別: 公式ドキュメント  
   主な対応章: 全体  
   役割: Git 操作と概念の土台  
   URL: `https://git-scm.com/doc`

2. Pro Git  
   種別: 公式書籍  
   主な対応章: 2章, 3章, 5章, 10章  
   役割: 履歴、ブランチ、復旧の補助  
   URL: `https://git-scm.com/book/en/v2`

### GitHub

3. Creating rulesets for a repository  
   種別: 公式ドキュメント  
   主な対応章: 6章  
   役割: rulesets の設計と設定の根拠  
   URL: `https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-rulesets/creating-rulesets-for-a-repository`

4. Managing a merge queue  
   種別: 公式ドキュメント  
   主な対応章: 7章  
   役割: merge queue の運用前提  
   URL: `https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/configuring-pull-request-merges/managing-a-merge-queue`

5. Events that trigger workflows  
   種別: 公式ドキュメント  
   主な対応章: 7章  
   役割: `merge_group` を扱う CI 連携の根拠

## 転記時のルール

- 本文で直接使っていないものは載せない
