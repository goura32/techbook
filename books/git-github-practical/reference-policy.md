# Reference Policy

## 目的

- `参考情報` 欄へ何を載せるかの判断基準を、完成原稿とは分けて管理する
- `back-matter.md` に制作メモを残しすぎないようにする

## 方針

- まず Git 本体、GitHub Docs、本書で明示した周辺機能の公式情報を優先する
- 時点依存の強い情報は、本文で言及したものだけ扱う
- 各カテゴリ 2 から 5 件程度を目安にし、過剰に増やしすぎない
- 参考情報欄の表記は `名称 / 種別 / URL` を基本にする

## 掲載カテゴリ案

1. Git 公式情報
2. GitHub 公式情報
3. リリースと保護設定関連

## 運用メモ

- `reference-sources.md` を候補台帳として使う
- `back-matter.md` には最終掲載する情報だけを残す
- 組版直前に URL を再確認して転記する
- GitHub の時点依存機能は rulesets、merge queue、`merge_group` に絞る
