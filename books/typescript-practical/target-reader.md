# Target Reader

## 想定読者

- JavaScript の実務経験があり、TypeScript を本格導入または再設計したい人
- 型は書いているが、設計にうまく活かせていない人
- Node.js とフロントエンドの両方で TypeScript を扱う人

## 前提知識

- JavaScript の基本文法
- npm 系パッケージ管理の基本
- Web 開発か Node.js 開発のいずれかの経験

## 読了後の到達目標

- TypeScript の型を設計判断に使える
- ランタイムとの境界で破綻しない実装方針を立てられる
- チームで保守しやすい TypeScript の開発環境を整えられる

## 読み方の目安

- Node.js 経験が中心の読者:
  - 1章から6章を主軸に読み、7章は UI 側の境界設計と画面モデルの参考として読む
- フロントエンド経験が中心の読者:
  - 1章から5章と7章を主軸に読み、6章は実行環境と API 境界、内部モデルの整理として読む
- 両方を扱う読者:
  - 1章から11章を順に読むと、本書の狙いが最もつながりやすい

## 対象外

- JavaScript 完全初心者向けの文法解説
- React や特定フレームワークだけに閉じた入門
- 型パズルだけを扱う高度テクニック集
