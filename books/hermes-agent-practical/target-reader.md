# Target Reader

## 想定読者

- OSS のコーディングエージェントを安全に実務導入したい開発者
- Hermes Agent を試したが、継続運用の設計に不安がある人
- Skills や MCP を使って自分用ワークフローを育てたい人
- CLI 中心の利用から、チームや長時間運用へ広げたい人
- `config.yaml` `.env` CLI 引数の関係を整理し、設定事故を減らしたい人

## 前提知識

- ターミナル操作の基本
- Git ベースの開発経験
- LLM や API キーの基本的な理解

## 読了後の到達目標

- Hermes Agent の導入、設定、運用方針を自分で決められる
- `config.yaml` `.env` CLI 引数のどこへ何を置くべきか判断できる
- Skills、MCP、Memory、Cron を実務に合わせて使い分けられる
- セキュリティと利便性のバランスを取りながら継続運用できる
- OpenCode や OpenClaw と比べたうえで、Hermes Agent を採用すべき条件を言語化できる

## 読み進め方の目安

- まず安全に導入したい読者は 1章から4章を主軸にすると全体像をつかみやすい
- 再利用可能な運用設計に関心が強い読者は 5章から9章を主軸にすると価値が伝わりやすい
- Gateway や Cron まで見据えた長時間運用が目的なら 1章、3章、8章から11章を重点的に読むとつながりやすい
- 他ツールと比較して導入判断をしたい読者は 1章から3章を押さえたうえで 12章へ進むと判断しやすい

## 対象外

- AI エージェント一般論だけを語る入門書
- 特定の 1 モデルに閉じた最適化本
- OpenCode や OpenClaw の詳細専用本
- GUI 操作だけを細かく追うクイックスタート集
