# Reference Policy

## 目的

- `参考情報` 欄へ何を載せるかの判断基準を、完成原稿とは分けて管理する
- `back-matter.md` に制作メモを残しすぎないようにする

## 方針

- まず Hermes Agent の公式 docs と公式 GitHub を優先する
- 日付依存の強い情報は、本文で言及したものだけ公開日やリリース日を併記する
- 各カテゴリ 2 から 5 件程度を目安にし、過剰に増やしすぎない
- 参考情報欄の表記は `名称 / 種別 / 日付 / URL` を基本にする

## 掲載カテゴリ案

1. Hermes Agent 公式情報
2. 主要機能の公式情報
3. 必要最小限の比較補助

## 運用メモ

- `reference-sources.md` を候補台帳として使う
- `back-matter.md` には最終掲載する情報だけを残す
- 組版直前に URL を再確認して転記する
- 比較対象の OpenCode / OpenClaw は、原則として本文での比較軸に必要な範囲へ留める
