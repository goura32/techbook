# Code Samples

## 目的

- 本文と付録で、どこまで設定断片や CLI 断片を載せるかの基準を固定する
- 読者が追える密度を保ちつつ、紙面で重くなりすぎることを避ける

## 方針

- 本文では、判断に直接効く短い設定断片と操作断片を優先する
- まとまった config、profile、skill 例は付録 C で補う
- `ForgeFlow` の全体像は付録 A、機能と責務の対応は付録 B で確認できるようにする
- セキュリティや approvals に関わる断片は、便利さとリスクを必ずセットで説明する

## 章ごとの重点

- 1章から4章:
  - install、setup、CLI、approval の短い断片を載せる
- 5章から7章:
  - skill 定義、MCP 設定、profile 設定、`SOUL.md` の断片を優先する
- 8章から10章:
  - memory 設定、cron、gateway 周辺を短く載せる
- 11章:
  - 安全運用ルールと事故時の確認手順を中心にする
- 12章:
  - 比較表を優先し、個別ツールの詳細手順には寄りすぎない
