# Appendix B. 主要機能と責務の対応

## この付録の役割

この付録は、本文で登場した主要機能を、どの責務に使うのかという観点で整理するためのものです。機能名を個別に覚えるのではなく、`何のために使うのか` で見直します。

## 主要機能

### Profiles

- 主な登場章: 7章
- 役割: state と運用目的を分ける

### Skills

- 主な登場章: 5章
- 役割: 再利用可能な手順を資産化する

### MCP

- 主な登場章: 6章
- 役割: 外部ツールやサーバーを明示的に接続する

### Memory / Memory Providers

- 主な登場章: 8章
- 役割: セッションをまたいで必要な文脈を持続する

### Checkpoints

- 主な登場章: 9章
- 役割: ファイル変更の巻き戻し安全装置

### Gateway / Cron

- 主な登場章: 10章
- 役割: 長時間運用とメッセージング、定期実行を支える

## 最後に見るべきこと

機能を足す順番を間違えると、Hermes Agent はすぐに複雑になります。まず profile と権限を分け、その後に skills、MCP、memory、cron を広げる順で考えると、運用を壊しにくくなります。
