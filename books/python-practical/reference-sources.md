# Reference Sources

## 目的

- `参考情報` 欄へ最終転記する候補を、本書で使った主張と対応づけて管理する
- KDP 用の後付へ転記するときに、リンク集ではなく本文に効いている情報だけを残す

## 優先候補

### Python

1. Python Documentation  
   種別: 公式ドキュメント  
   主な対応章: 全体  
   役割: 標準ライブラリと言語仕様の土台  
   URL: `https://docs.python.org/`

2. What’s New in Python 3.14  
   種別: 公式ドキュメント  
   日付: 2025年10月7日公開の 3.14 系解説  
   主な対応章: 9章  
   役割: 3.14 世代の変化を扱う根拠  
   URL: `https://docs.python.org/3/whatsnew/3.14.html`

### Packaging

3. Writing your `pyproject.toml`  
   種別: Python Packaging User Guide  
   主な対応章: 7章  
   役割: `pyproject.toml` を中心に据える説明の根拠  
   URL: `https://packaging.python.org/en/latest/guides/writing-pyproject-toml/`

4. `pyproject.toml` specification  
   種別: Python Packaging User Guide  
   主な対応章: 7章  
   役割: `pyproject.toml` の標準的な位置づけ  
   URL: `https://packaging.python.org/en/latest/specifications/pyproject-toml/`

## 転記時のルール

- 後付には 6 件前後を上限目安にする
- 本文で直接使っていないものは載せない
- 日付依存の強い項目だけ公開日を併記する
- URL は最終組版直前に確認して転記する
