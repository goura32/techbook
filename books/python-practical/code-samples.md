# Code Samples

## 目的

- 本文と付録で、どこまでコードを載せるかの基準を固定する
- 読者が追える密度を保ちつつ、紙面で重くなりすぎることを避ける

## 方針

- 本文では、判断に直接効く短い断片を優先する
- 連続した構成やファイル間のつながりは付録 C で補う
- `OpsBox` の全体像は付録 A、型と関数の対応は付録 B で確認できるようにする
- `pyproject.toml` や `pytest` 設定の例は、最小限だが実務でそのまま参考になる粒度を目指す

## 章ごとの重点

- 1章から4章:
  - dataclass、`TypedDict`、変換関数の短い断片を見せる
- 5章:
  - 設定読み込み、例外、ログ、CLI 引数の最小構成を見せる
- 6章:
  - `pytest` のテスト例、fixture、`monkeypatch`、`tmp_path` を短く載せる
- 7章:
  - `pyproject.toml` と依存関係定義の最小例を載せる
- 8章:
  - `asyncio.TaskGroup`、`asyncio.to_thread()`、タイムアウトの例を載せる
- 9章:
  - 3.14 の変更点は断片より判断軸を優先する
- 10章:
  - API レスポンスを内部モデルへ変換する断片を載せる
- 11章:
  - チェックリストと短い改善前後比較を中心にする
