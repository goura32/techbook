# Reference Policy

## 目的

- `参考情報` 欄へ何を載せるかの判断基準を、完成原稿とは分けて管理する
- `back-matter.md` に制作メモを残しすぎないようにする

## 方針

- まず Python 本体、Python Packaging User Guide、本書で明示した周辺ツールの公式情報を優先する
- 日付依存の強い情報は、本文で言及したものだけ版や公開日を併記する
- 各カテゴリ 2 から 5 件程度を目安にし、過剰に増やしすぎない
- 参考情報欄の表記は `名称 / 種別 / 版または日付 / URL` の順でそろえる

## 掲載カテゴリ案

1. Python 公式情報
2. パッケージ管理と配布
3. テストと周辺ツール

## 運用メモ

- `reference-sources.md` を候補台帳として使う
- `back-matter.md` には最終掲載する情報だけを残す
- 組版直前に URL を再確認して転記する
- 周辺ツールは、本文で明示的に名前を出しているものだけを追加する
- 現時点の周辺ツール掲載範囲は `uv` `pytest` までとし、`pip` や `venv` は一般概念として扱う
