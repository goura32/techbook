# Target Reader

## 想定読者

- Python を使っているが、実務での設計や運用に不安がある人
- 業務自動化やバックエンド補助を Python で担いたい人
- 他言語経験はあるが、Python の流儀を押さえたい人
- 小さなスクリプトを、チームで運用できるツールへ育てたい人

## 前提知識

- 基本的なプログラミング経験
- Python の基本構文を一通り触った経験
- `venv` や `pip install` を一度は使った経験があると読みやすい

## 読了後の到達目標

- 実務で読みやすく壊れにくい Python を書ける
- テスト、設定、配布、非同期処理まで見通して設計できる
- Python を便利スクリプトで終わらせず、運用可能な資産として扱える
- Python 3.14 世代の変更を、自分の現場へ採用するかどうか判断できる

## 読み進め方の目安

- CLI や自動化の関心が強い読者は 1章から7章を主軸にするとつながりやすい
- API 連携やバッチ処理の関心が強い読者は 1章から5章、8章、10章を主軸にすると読みやすい
- チーム運用やコードベース改善が主目的なら 1章から6章、11章を先に押さえると効果が高い

## 対象外

- データサイエンス専用の分析手法
- Django や FastAPI だけに寄せたフレームワーク入門
- 完全初心者向けの文法教本
- C 拡張や CPython 内部実装の詳細解説
