# Outline

## 書籍の目的

- Python を業務自動化とアプリケーション開発の両面で、安全かつ保守しやすく使うための判断軸を渡す
- 文法入門で終わらず、標準ライブラリ、型ヒント、テスト、パッケージ管理、非同期まで実務に必要な範囲をつなげる

## 仮タイトル

- 技術の輪郭 Python
- サブタイトル案: 標準ライブラリ、型、テスト、3.14 時代の運用まで

## 章構成案

1. Python を実務で使うための見取り図
2. 文法の先にある Python らしさ
3. データ構造と標準ライブラリの使いどころ
4. 型ヒントと読みやすい API 設計
5. 例外、ログ、設定、CLI
6. テスト、自動化、品質管理
7. パッケージ管理と配布
8. 非同期処理と I/O
9. Python 3.14 時代の実務判断
10. Web/API 連携と外部サービス境界
11. 長く運用する Python コードベース

## 各章の要点

- 1章: Python が得意な領域と苦手な領域を整理する
- 2章: イディオム、可読性、過剰抽象化の避け方を扱う
- 3章: `pathlib`、`collections`、`datetime`、`subprocess` などを実務目線で整理する
- 4章: 型ヒントを保守性へどう結びつけるかを扱う
- 5章: CLI ツールや業務スクリプトで必要な基礎を扱う
- 6章: `pytest` を中心に、回帰防止と設計の接点を扱う
- 7章: `pyproject.toml`、依存関係、仮想環境、配布を扱う
- 8章: 同期/非同期の選択基準と設計上の注意を扱う
- 9章: Python 3.14 の変更点、free-threaded Python、subinterpreters、注釈評価の変化を実務目線で扱う
- 10章: API 呼び出し、認証、例外処理、リトライの設計を扱う
- 11章: リファクタリング、性能、チーム運用を扱う

## 他書との役割分担メモ

- `TypeScript` とは異なり、本書は型よりも標準ライブラリと運用基盤を厚く扱う
- `Git & GitHub` にあるチームレビューやブランチ戦略の詳細は持ち込まない
- `Hermes Agent` で出てくる Python 環境構築は、必要に応じて本書か共通説明を参照する形にする
- 競合の多い入門書との差別化のため、便利スクリプトではなく「運用可能な Python」を一貫した軸にする
