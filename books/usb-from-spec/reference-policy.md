# Reference Policy

## 目的

- USB のように改訂が続く規格系の本で、どの資料を後付へ残すかの方針を固定する

## 方針

- USB-IF の公式情報を最優先にする
- 本文で直接使った判断材料だけを残す
- 世代差分や改訂日が意味を持つものだけ日付を併記する
- 特定ベンダ資料は、本文で不可欠な場合を除き参考情報へ入れない

## 扱い分け

- 仕様の根拠: USB-IF Document Library
- 概要説明: USB-IF 技術ページ
- 試験と解析: USB-IF の interop / compliance 文書

## 運用メモ

- `reference-sources.md` を管理台帳として使う
- 組版直前に URL と日付を再確認する
