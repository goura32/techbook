# 7章 USB 3.2 と高速側の論点

USB 3.x 系は、多くの開発者を名前だけで混乱させてきました。USB 3.0、3.1、3.2、Gen1、Gen2、2x2。ここで大切なのは、名前を暗記することではなく、`USB 2.0 の土台に高速側の経路が重なる` という構造を理解することです。

## 7-1. USB 2.0 は消えない

高速世代に入っても、USB 2.0 的な列挙や class の世界が消えるわけではありません。多くの現場で起きるのは、marketing 上は `USB 3.2 対応` でも、実際の不具合は USB 2.0 的な列挙や descriptor の話だった、というケースです。高速化は古い論点を置き換えるのではなく、観測点を増やします。

## 7-2. Gen1 / Gen2 / lane の考え方

USB 3.2 の理解で必要なのは、`速度名` より `どの経路が何本あり、どこが cable や host に依存するか` を見ることです。Gen1 と Gen2 の違い、複数 lane の扱い、hub や dock が経路へ与える影響を頭に入れておくと、`USB-C なのに期待した速度が出ない` 現象を説明しやすくなります。

## 7-3. cable、hub、host controller が増やす観測点

高速側では、device 単体より環境差が効きやすくなります。cable の品質、hub の有無、dock の中の再構成、host controller の差。USB 2.0 では平気だったものが、高速側の path でだけ不安定になるのは普通に起きます。だから `直結では安定だが dock 経由で不安定` といった症状は、高速側の観測点として先に切り出したほうがよいです。

実務でよくあるのは、同じ device が `短い直結 cable では安定` `長い cable では Gen が落ちる` `特定 dock 経由だと enumeration 自体はするが高速 mode に入らない` といった差です。ここで `device firmware が悪いはずだ` と決めつけるより、まず経路を減らして `host 直結` `別 cable` `別 host controller` の 3 点比較を作るほうが速いです。高速側は、論理仕様だけでなく経路品質と相手機能差の影響を強く受けます。

## 7-4. backwards compatibility の実態

互換性があるとは、必ずしも期待した速度や機能で動くことを意味しません。多くの場合は `最低限どこへフォールバックするか` の話です。だから support 文書でも、最大速度だけでなく `どの cable 条件で、どの host で、どの mode へ落ちるか` を説明できることが重要です。

たとえば `USB Type-C でつながる` ことと `期待した SuperSpeed path が有効` であることは別です。USB 2.0 の D+ / D- は生きているため見かけ上は普通に動いていても、高速差動対の経路や相手機能が揃わなければ USB 2.0 相当へ落ちます。ユーザーは `動くが遅い` と感じ、開発側は `一応認識するので大丈夫そうだ` と誤解しやすいところです。

## 7-5. 高速側だけ不安定になるときの見方

この表現で言いたいのは、`USB 2.0 相当では成立するが、高速 path に入ると不安定` という状態です。ここで最初に見るべきは、descriptor や class よりも、cable 条件、host controller、hub / dock 経由の有無、温度や電力条件です。高速側では `論理的には正しいが環境条件で崩れる` ケースが増えます。

観測の順番としては、まず `期待した speed へ本当に入っているか` を host 側の情報で確認し、その次に path を短くして比較し、最後に analyzer や electrical test を検討する流れが現実的です。最初から packet の内容へ潜っても、そもそも mode が落ちているだけなら説明になりません。高速側は、まず `どの mode で成立しているか` を見極めるところから始めるべきです。

## 7-6. marketing 文言と仕様上の能力

良い仕様書や製品情報は、`最大速度` だけでなく、`どの条件でその速度が有効か` を示します。悪い情報は `USB 3.2 対応` の一言だけで済ませます。本書が marketing 名より layer を優先するのは、読者が最終的に必要とするのが `どの条件で、どの mode が成立するか` だからです。

## 7-7. この章のまとめ

USB 3.2 を理解するとは、高速化そのものより `高速側の追加観測点` を理解することです。次の章では、現代の USB を大きく変えた USB Type-C を、connector と配線と役割の観点から整理します。
