# Reference Sources

## 目的

- `参考情報` 欄へ最終転記する候補を、本書で使った主張と対応づけて管理する
- リンク集にならず、本文へ効いている資料だけを残す

## 転記時のルール

- 後付には 8 件前後を上限目安にする
- 本文で直接使っていないものは載せない
- 日付依存の強い項目だけ公開日を併記する
- URL は最終組版直前に確認して転記する
