# Target Reader

## 想定読者

- USB 接続デバイスを扱う組み込み・ファームウェア開発者
- USB デバイスをソフトウェア側から制御、解析、デバッグしたい開発者
- Type-C や PD を含めて USB の全体像を整理したい人
- 規格書を読み始めたが、どこから押さえるべきか分からない人

## 前提知識

- 基本的なプログラミング経験
- バイナリ、シリアル通信、電圧や電流のごく基本的な概念
- OS 上でデバイスを扱った経験があると読みやすい

## 読了後の到達目標

- USB の列挙、descriptor、転送方式を説明できる
- USB Type-C と USB PD の関係を、形状と電力の両面から整理できる
- USB 2.0、USB 3.2、USB4 の位置づけを marketing 名ではなく実装視点で理解できる
- USB の不具合を、物理、電力、列挙、class、driver のどこで切り分けるべきか判断できる

## 読み進め方の目安

- まず USB の土台を固めたい読者は 1章から4章を主軸に読むと全体が見えやすい
- Type-C や電力に関心が強い読者は 5章から7章を重点的に読むとつながりやすい
- 実装や解析が主目的なら 3章、4章、8章、9章、10章を主軸にすると実務へ戻しやすい
- 規格書の読み方を掴みたい読者は 1章、3章、6章、10章を通して見ると判断軸が残りやすい

## 対象外

- 電気回路設計だけに特化した高速信号完全入門
- 特定の MCU ベンダや USB IP コア専用の実装本
- USB4 物理層だけを深掘りする専門書
- 単なる製品レビューや買い方ガイド
