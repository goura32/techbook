# Final Assembly Checklist

## 目的

- 組版直前に、原稿全体を KDP 向けに最終確認する
- 本文、付録、図表、前付、後付の接続漏れを防ぐ

## 原稿構成

- [ ] 前付が `扉 -> はじめに -> 本書の読み方 -> 目次` の順で揃っている
- [ ] 本文 1章から11章の順序が目次と一致している
- [ ] 付録 A / B / C の並びが本文参照と一致している
- [ ] 後付が `おわりに -> 参考情報 -> 著者紹介 -> 奥付` の順で揃っている

## 本文

- [ ] 各章に制作用メモが残っていない
- [ ] 章タイトルと見出し表記が統一されている
- [ ] 付録参照が `付録 A` `付録 B` `付録 C` の表記で揃っている
- [ ] 時点依存の記述は必要箇所だけに絞られている

## サンプルと用語

- [ ] `TraceDock` の構造と power / data role 前提が本文と付録で揃っている
- [ ] `descriptor` `endpoint` `power role` `data role` `USB PD` などの用語が揃っている
- [ ] Type-C と PD の説明が混線していない

## 図表

- [ ] 図表番号が本文順に並ぶ
- [ ] 図表キャプションが本文の主張と一致している
- [ ] 図表の差し込み位置が `figures.md` と矛盾していない
- [ ] 図表本文が長すぎて見開きで詰まりすぎない

## 前付・後付

- [ ] `はじめに` のトーンが本文 1章と自然につながる
- [ ] `本書の読み方` が想定読者と一致している
- [ ] `おわりに` が本書全体の視点を回収できている
- [ ] 著者紹介と奥付が最低限の情報を満たしている
- [ ] 奥付の著者名と連絡先メールアドレスが確定している
- [ ] 発行日が未確定の場合でも、差し替え位置が明確になっている

## KDP 向け確認

- [ ] 前付・後付を含めたページバランスが大きく崩れていない
- [ ] 目次に含める見出し粒度が決まっている
- [ ] 参考情報の URL / 版情報を最終転記する準備がある
- [ ] 参考情報がリンク集になりすぎず、本文と結びつく範囲に絞られている
- [ ] `reference-sources.md` の候補と後付の参考情報欄が一致している
- [ ] 最終版に載せない制作支援ファイルが本文原稿へ混入していない
